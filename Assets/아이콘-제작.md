# Mac Color Match 앱 아이콘

제작: built-in image_gen, 투명 배경. 원본 PNG는 AppIcon-source.png에 보존.

프롬프트: Mac Color Match용 macOS 앱 아이콘. 투명 정사각형 캔버스 중앙에 충분한 여백을 둔 짙은 남색 둥근 사각형 타일. 은빛 테두리의 겹친 두 모니터에 같은 따뜻한 색에서 차가운 색으로 이어지는 스펙트럼. 작은 Dock 크기에서도 읽히는 단순한 형태, 절제된 입체감, 글자·Apple 로고·목업 없음.

패키징: sips로 16, 32, 128, 256, 512pt 각각 1x/2x PNG 10개 생성. 최대 1024px. iconutil로 AppIcon.icns 생성, CFBundleIconFile=AppIcon으로 연결.

Apple 규격 참고: https://developer.apple.com/library/archive/documentation/Xcode/Reference/xcode_ref-Asset_Catalog_Format/IconSetType.html

전통적인 ICNS 앱 아이콘이며 Icon Composer의 동적 Liquid Glass 레이어 아이콘은 아님.
